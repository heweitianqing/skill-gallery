## English

### Short (one post)

> What do web-design agent skills actually change? I ran three popular SKILL.md skills on the same three prompts in Claude Code and Codex, with and without each skill, and put every result side by side. One run per cell, no picking, failures included.
> https://heweitianqing.github.io/skill-gallery/

### Longer (forum or blog)

> **skill-gallery: the same prompts, with and without agent skills**
>
> There are a lot of agent skills that promise better front-end work, but their READMEs show hand-picked examples, and it is not always clear how to use the same skill in Claude Code and in Codex.
>
> skill-gallery runs each skill on three fixed prompts (a SaaS landing page, a data dashboard, a portfolio and blog) in both agents, next to a baseline without any skill. Every run happens in a throwaway environment with nothing from my own setup loaded, the logs have to show the skill being used, and each cell is generated once and published as is.
>
> The gallery lets you flip between desktop and mobile screenshots, open each original page in a sandbox, and read the run record behind it (model, time, tokens, whether the skill fired). Every skill page also has the install and usage steps for both agents.
>
> v0.1 covers `frontend-design`, `ui-ux-pro-max` and `web-design-engineer`. Suggestions for the next skills are welcome.

### 长版（论坛或博客）

> **skill-gallery：同一道题，用和不用 skill 的网页对比**
>
> 现在有很多号称能让前端更好看的 agent skill，但 README 里放的都是精选案例，同一个 skill 在 Claude Code 和 Codex 里怎么装、怎么用，也常常说不清楚。
>
> skill-gallery 用三道固定的题（SaaS 落地页、数据看板、个人博客和作品集），在两个 agent 里分别跑每个 skill，并和完全不用 skill 的基线对比。每次运行都在一次性的隔离环境里进行，不加载我自己的任何配置；日志里必须能看到 skill 真的被调用了；每格只生成一次，结果原样公开。
>
> 画廊里可以切换桌面和手机截图，在沙箱里打开每个原始页面，也能看到每格背后的运行记录（模型、耗时、token、skill 是否触发）。每个 skill 页面还写了它在两个 agent 里的安装和调用方法。
>
> v0.1 包含 `frontend-design`、`ui-ux-pro-max` 和 `web-design-engineer`，欢迎推荐下一批要测的 skill。

## 日本語

### 短い版（1 投稿）

> Web デザイン系の agent skill は実際に何を変えるのか。人気の SKILL.md skill 3 つを、Claude Code と Codex でそれぞれ同じ 3 つのプロンプトで実行し、skill なしの結果と並べました。各セル 1 回だけ生成し、結果は選り好みせず、失敗もそのまま公開しています。
> https://heweitianqing.github.io/skill-gallery/

### 長い版（フォーラムやブログ向け）

> **skill-gallery：同じプロンプトを skill あり・なしで比べる**
>
> フロントエンドの見た目を良くするという agent skill はたくさんありますが、README に載っているのは選び抜かれた例ばかりで、同じ skill を Claude Code と Codex でどう使うのかも分かりにくいことがあります。
>
> skill-gallery では、固定した 3 つのプロンプト（SaaS のランディングページ、データダッシュボード、ブログ兼ポートフォリオ）で各 skill を両方の agent で実行し、skill を使わないベースラインと比べています。実行はすべて使い捨ての環境で行い、私自身の設定は一切読み込みません。skill が実際に使われたことをログで確認し、各セルは 1 回だけ生成してそのまま公開しています。
>
> ギャラリーでは、デスクトップとモバイルのスクリーンショットを切り替えたり、元のページをサンドボックスで開いたり、各セルの実行記録（モデル、時間、トークン、skill が発動したか）を確認したりできます。skill ごとのページには、両方の agent でのインストールと呼び出しの手順も載せています。
>
> v0.1 の対象は `frontend-design`、`ui-ux-pro-max`、`web-design-engineer` です。次に試す skill の提案も歓迎します。
